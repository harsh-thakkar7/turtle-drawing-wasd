# Turtle Drawing WASD

A creative drawing tool using Python turtle graphics, controlled by WASD keys for freehand art creation.

## Features

- WASD key controls for smooth drawing
- Clear and reset functionality
- Simple and intuitive interface

## How to Run

```bash
python main.py
```

## Controls

- W: Move forward
- A: Turn left
- S: Move backward
- D: Turn right
- C: Clear and reset

## Requirements

- Python 3.x
- No external dependencies (uses built-in `turtle` module)
